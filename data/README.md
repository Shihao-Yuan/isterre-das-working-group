# Data resources

Pointers to example, public, and shared DAS datasets useful for the working group.

This folder will collect documents such as:

- **Public / open datasets** — links to published DAS data with brief descriptions
- **Internal shared data** — how to request or access ISTerre-related datasets (paths, contacts, access rules)
- **Example subsets** — small illustrative samples for training and testing (when appropriate)

Large binary archives should generally live on institutional storage, not in this repository. For compute platforms, storage systems, and transfer guidance, see [`../computing/`](../computing/). Contributions and updates from the working group are welcome.
