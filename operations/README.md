# Operations

Practical guidance for deploying and operating the ISTerre DAS instruments.

This folder will collect documents such as:

- **Suggested operating workflow** — end-to-end steps from booking through acquisition and handoff
- **Parameter setup** — recommended interrogator / acquisition settings for common use cases
- **Field checklist** — pre-deployment and on-site checks before and during recording
- **Troubleshooting notes** — common issues and how to resolve them

Contributions and updates from the working group are welcome.
