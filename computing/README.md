# Computing

Guidance on computing resources and storage available to the ISTerre DAS working group.

This folder will collect documents such as:

- **Compute access** — clusters, workstations, and how to request accounts
- **Storage options** — scratch vs long-term locations, quotas, and recommended use
- **Data transfer** — practical tips for moving large DAS volumes
- **Shared environments** — modules, containers, or common software setups when available

For dataset catalogs and access pointers, see [`../data/`](../data/). Contributions and updates from the working group are welcome.
