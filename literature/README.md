# Literature

Shared reading lists and literature resources for DAS-related research at ISTerre.

This folder will collect documents such as:

- **Core reading list** — foundational and frequently cited DAS papers
- **Topic notes** — short summaries or annotated bibliographies by theme (e.g. earthquake, ambient noise, infrastructure)
- **Suggested readings** — papers recommended by working group members

Prefer links and citations over redistributing copyrighted PDFs. Contributions from the working group are welcome.
