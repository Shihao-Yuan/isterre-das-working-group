# Meetings

Agendas, notes, and action items for ISTerre DAS working group meetings.

## How we organize files

Create **one Markdown file per meeting**, named by date:

```text
YYYY-MM-DD.md
```

Example: [`2026-10-05.md`](2026-10-05.md)

## Agenda sections

1. **Meeting details** — date, start/end time, room, online link, chair, note-taker
2. **Seminar** — speaker, affiliation, title, abstract, presentation link
3. **Recent updates and announcements** — projects, datasets, publications, opportunities, events
4. **Instrument update** — availability, deployments, maintenance, problems, training needs
5. **Discussion items** — topic, who introduces it, time, decision or input needed
6. **Decisions and actions** — decisions, tasks, responsible people, deadlines
7. **Next meeting** — proposed date, speaker or main topic

Contributions and updates from the working group are welcome.
